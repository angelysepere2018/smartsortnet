SmartSortNet

Organic vs Inorganic Waste Classification with AlexNet

A deep-learning sustainability project designed to help reduce waste contamination and support cleaner recycling streams on campus.

Overview Problem Dataset Technical Experiments Visualizations Results Takeaways Links

Project Overview

SmartSortNet is a convolutional neural network (CNN) that classifies waste as Organic or Inorganic. This project demonstrates how AI can support recycling accuracy and reduce contamination on campus.

Problem & Motivation

Why This Matters

  • Recycling contamination leads to entire bins being discarded.
  • Organic waste mixed with plastics causes spoilage.
  • South Florida ecosystems are sensitive to plastic pollution.
  • Students often only have seconds to choose the correct bin.

Project Goal

SmartSortNet provides a foundation for real-time image-based waste sorting, enabling future smart bins or mobile tools to guide students.

Dataset

Classes

  • Organic: peels, leftover food, plant matter.
  • Inorganic: bottles, cans, jars, cardboard, wrappers.

Preprocessing

  • Resized to 224×224.
  • RGB normalized (ImageNet stats).
  • Train / validation / test split.
  • Optional augmentation.

Technical Approach

Model Architecture

  • AlexNet pretrained on ImageNet.
  • Convolutional + max pooling layers extract features.
  • Fully connected layers classify the waste type.
  • Final layer modified to 2 outputs.

Training Setup

  • PyTorch framework.
  • Adam optimizer.
  • Cross-entropy loss.
  • Tracked accuracy/loss each epoch.
  • Logged in Weights & Biases.

Results

The best run alexnet_bs32_lr1e-4_noaug achieved around 95% validation accuracy. Other runs, including ResNet-18, reached 93–94%.

  • Batch size 32 gave stable performance.
  • Learning rate 1e-4 outperformed 1e-3.
  • Augmentation improved generalization.
  • AlexNet slightly beat ResNet18.

Takeaways & Future Work

  • CNNs can effectively sort organic vs inorganic waste.
  • Hyperparameters greatly affect accuracy.
  • Future: compost, landfill, recycling subclasses.
  • Deploy in smart bins or a mobile app.
