SmartSortNet

Organic vs Inorganic Waste Classification with AlexNet

A nature-focused deep learning project that uses image classification to help keep recyclable streams clean and support more sustainable waste habits on campus.

🌿 Project Overview

SmartSortNet is a convolutional neural network (CNN) project that classifies waste images into Organic and Inorganic categories. By focusing on the boundary between compostable food waste and non-biodegradable packaging, the project explores how AI can support cleaner recycling streams and healthier ecosystems.

🗑️ Problem & Motivation

Why This Matters

  • Bin contamination causes entire batches of recyclables to be landfilled.
  • Organic waste mixed with inorganic items can spoil recovery streams.
  • South Florida’s waterways and coastal ecosystems are sensitive to plastics and microplastics.
  • Busy students often have less than a second to decide “Which bin?”

Project Goal

SmartSortNet aims to support nature by reducing avoidable contamination. A model that can visually distinguish food scraps from packaging is a first step toward camera-based “smart bins” or mobile tools that guide students toward the right bin in real time.

📸 Dataset

Classes

  • Organic: fruit and vegetable peels, leftover food, coffee grounds, plant matter.
  • Inorganic: plastic bottles, cans, glass jars, paper, cardboard, wrappers.

The dataset comes from a public waste classification collection and is used strictly for educational and research purposes.

Preprocessing

  • Images resized to 224 × 224 pixels (AlexNet input size).
  • Converted to RGB tensors and normalized with ImageNet mean and std.
  • Data split into training, validation, and test sets.
  • For some experiments, data augmentation (flips, rotations, crops) is applied.

🧠 Technical Approach: AlexNet-Based Classifier

Model Architecture

  • Base network: AlexNet pretrained on ImageNet.
  • Convolutional layers extract low-level (edges, colors) and higher-level shapes.
  • Max-pooling layers gradually reduce spatial size.
  • Fully connected layers interpret features for classification.
  • Final layer replaced with a 2-unit output (Organic vs Inorganic).

Training Setup

  • Framework: PyTorch.
  • Loss: cross-entropy for two-class classification.
  • Optimizer: Adam with different learning rates tested.
  • Metrics tracked per epoch: training and validation accuracy and loss.
  • Logging: Weights & Biases (wandb) for runs, curves, and confusion matrices.

🔬 Experiments

These experiments explore how hyperparameters and architecture choices affect the model’s ability to recognize organic vs inorganic waste, and ultimately, to protect recycling streams and the environment.

Batch Size

Compare batch sizes 16 and 64 to see how training stability and final accuracy change.

Learning Rate

Test learning rates 0.001 vs 0.0001 to balance fast learning with stable convergence.

Data Augmentation

Train with and without augmentation (random flips, rotations, crops) to measure improvements in generalization to unseen waste images.

Model Comparison

Compare AlexNet with a second CNN such as ResNet-18 to understand which architecture better separates organic vs inorganic waste.

📊 Results

Across all experiments, the model consistently reached high performance on the organic vs inorganic classification task. The best run, alexnet_bs32_lr1e-4_noaug, achieved a validation accuracy of roughly 95%. Several other runs (including ResNet-18 with similar settings) clustered around 93–94%.

  • Best batch size: a batch size of 32 gave the strongest overall performance and stable learning.
  • Best learning rate: 1e-4 worked well. The higher learning rate 1e-3 led to much poorer performance (validation accuracy around 0.6), showing that it was too aggressive.
  • Data augmentation: mild augmentation slightly changed validation accuracy but did not clearly beat the best non-augmented run. However, it can still help with robustness to new images.
  • Model comparison: AlexNet with tuned hyperparameters slightly outperformed ResNet-18 on this dataset, but both architectures reached strong validation accuracy above 90%.

These results suggest that careful tuning of learning rate and batch size matters more than changing architectures for this small, two-class waste dataset.

🌱 Key Takeaways & Future Work

  • SmartSortNet shows that CNNs can meaningfully separate organic and inorganic waste from images.
  • Even a simple two-class system can support better everyday recycling decisions on campus.
  • Performance is strongly influenced by data quality, class balance, and augmentation choices.
  • Future directions include more classes (compost, landfill, mixed recycling types) and real-world testing.
  • Long-term vision: deploy the model in smart bins or mobile apps that help keep campus greener.
