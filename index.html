SmartSortNet

Organic vs Inorganic Waste Classification with AlexNet

A deep-learning sustainability project designed to help reduce waste contamination and support cleaner recycling streams on campus.

Overview Problem Dataset Technical Experiments Visualizations Results Takeaways Links

Project Overview

SmartSortNet is a convolutional neural network (CNN) project that classifies waste into two classes: Organic and Inorganic. It explores how deep learning can support cleaner recycling streams and better sustainability habits on campus.

Problem & Motivation

Why This Matters

  • Recycling contamination leads to entire bins being landfilled.
  • Organic waste mixed with plastics causes spoilage.
  • South Florida ecosystems are sensitive to plastic pollution.
  • Students often have seconds to choose the correct bin.

Project Goal

SmartSortNet aims to provide a foundation for real-time waste identification, forming the basis for future camera-enabled smart bins or mobile sustainability tools.

Dataset

Classes

  • Organic: fruit/vegetable peels, leftover food, plant material.
  • Inorganic: plastic bottles, cans, cardboard, wrappers.

Preprocessing

  • Images resized to 224 × 224 pixels.
  • Normalized with ImageNet mean and std.
  • Split into train, validation, and test sets.
  • Augmented with flips, rotations, and crops in some runs.

Technical Approach

Model Architecture

  • Base model: AlexNet pretrained on ImageNet.
  • Convolutional layers extract edges, textures, shapes.
  • Max-pooling layers reduce spatial dimensions.
  • Fully connected layers perform final classification.
  • Final layer replaced with 2 outputs (Organic vs Inorganic).

Training Setup

  • PyTorch framework.
  • Cross-entropy loss.
  • Adam optimizer with multiple learning rates tested.
  • Logged accuracy/loss each epoch.
  • Tracked and visualized with Weights & Biases.

Experiments

Controlled experiments tested how hyperparameters and architecture changes affect performance.

Batch Size

Learning Rate

Tested 1e-4 vs 1e-3.

Data Augmentation

Used flips/rotations/crops to improve generalization.

Model Comparison

Results

The best-performing configuration, alexnet_bs32_lr1e-4_noaug, achieved a validation accuracy of approximately 95%. Other AlexNet and ResNet-18 configurations reached around 93–94%.

  • Batch size 32 was most consistent.
  • Learning rate 1e-4 gave stable convergence.
  • Learning rate 1e-3 was too high (poor accuracy).
  • Augmentation slightly helped robustness.
  • AlexNet slightly outperformed ResNet-18 on this dataset.

Takeaways & Future Work

  • CNNs can effectively distinguish organic vs inorganic waste.
  • Hyperparameters strongly shape performance.
  • Future work: add compost, landfill, recycling subclasses.
  • Long-term vision: deploy in smart bins or a mobile sorting assistant.
