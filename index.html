SmartSortNet

Classifying Organic vs Inorganic Waste with AlexNet

MAP 2192 – Florida Atlantic University

Overview Problem Dataset Method Experiments Results Future Work Links

Project Overview

SmartSortNet is a deep learning project designed to classify waste into organic and inorganic categories using the AlexNet CNN architecture. This project supports sustainability efforts by exploring AI-driven waste sorting solutions that could help reduce recycling contamination.

Problem & Motivation

  • Students often place items in the wrong bin on campus.
  • Incorrect sorting contaminates recycling streams.
  • Contamination leads to more waste ending up in landfills.
  • South Florida ecosystems suffer heavily from plastic and inorganic waste pollution.

SmartSortNet aims to demonstrate how machine learning can support proper waste sorting and encourage sustainable habits across campus.

Dataset

The dataset contains two main waste categories:

  • Organic: fruit peels, food scraps, vegetables, plant material
  • Inorganic: plastic bottles, cans, cardboard, packaging

All images were resized to 224×224 and normalized using ImageNet statistics.

Method: AlexNet Model

The model uses a modified version of AlexNet:

  • Pretrained weights on ImageNet
  • Final layer replaced with a 2-class output (organic vs inorganic)
  • Training with Adam optimizer and cross-entropy loss

Experiments

Several experiments were conducted to study model performance:

  • Batch size comparison: 16 vs 64
  • Learning rate tuning: 0.001 vs 0.0001
  • Data augmentation vs no augmentation
  • AlexNet vs ResNet-18 model comparison
